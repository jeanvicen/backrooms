# Backrooms: Lost in the Liminal

Um jogo de terror psicológico em primeira pessoa baseado no universo das Backrooms, desenvolvido em Unity com URP (Universal Render Pipeline).

## 📋 Visão Geral

**Gênero:** Horror psicológico / Survival / Exploração  
**Perspectiva:** Primeira pessoa  
**Engine:** Unity 2024.2+ com URP  
**Plataformas:** PC (Windows, Linux), PlayStation 5, Xbox Series X/S  

## 🎮 Características Principais

- **7 Níveis únicos** das Backrooms, cada um com atmosfera e mecânicas distintas
- **Sistema de Sanidade** que afeta a percepção e controles do jogador
- **Múltiplas Entidades** com IA avançada de patrulha e perseguição
- **Gráficos de alta qualidade** com iluminação dinâmica e pós-processamento
- **Sistema de Inventário** com gerenciamento de recursos
- **Narrativa ambiental** através de notas, gravações e símbolos

## 🏢 Estrutura dos Níveis

1. **Level 0 - The Lobby**: Tutorial introdutório, corredores infinitos de escritório
2. **Level 1 - Habitable Zone**: Armazéns industriais, primeiras entidades
3. **Level 2 - Pipe Dreams**: Túneis de manutenção, escuridão e calor
4. **Level 3 - The Electrical Station**: Subestação elétrica, puzzles elétricos
5. **Level 4 - Abandoned Office**: Área segura, recuperação de sanidade
6. **Level 5 - Terror Hotel**: Hotel vintage, stealth obrigatório
7. **Level 6 - Lights Out**: Escuridão total, visibilidade limitada
8. **Level 7 - Thalassophobia**: Piscina abandonada, confronto final

## 🚀 Instalação e Desenvolvimento

### Pré-requisitos
- Unity Hub instalado
- Unity 2024.2 ou superior
- Módulo URP (Universal Render Pipeline) instalado

### Passos para Configurar

1. Clone este repositório
2. Abra o Unity Hub e adicione o projeto
3. Selecione a Unity 2024.2+ para abrir o projeto
4. Aguarde a importação dos assets
5. Abra a cena `Assets/Scenes/Level0_ProTOTYPE.unity` para começar
